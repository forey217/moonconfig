## 项目简介

MoonConfig 是使用 MoonBit 编写的 JSON 配置变更工具，提供结构化比较、原子 JSON Patch 和三方合并。对象的独立字段修改自动合并；同字段的不同修改输出包含 base、ours、theirs 的冲突报告，区分删除和显式 null。CLI 与浏览器工作台共享 MoonBit 核心，并保留大整数精度。

## 使用场景

审查服务配置修改、比较两个配置版本、将审核后的补丁应用到配置，以及合并两个人基于同一版本完成的修改。项目是通用库与演示工具，当前没有真实生产部署或用户采用数据。

## 技术实现

使用 MoonBit 标准库 JSON，独立实现路径处理、六种补丁操作、十进制数值比较和递归三方合并。核心可在 JavaScript 与 WebAssembly GC 后端运行；浏览器展示与 Node 文件输入输出为薄层适配。

## 当前完成情况

## 三分钟演示脚本

1. 打开本地演示，展示独立修改：端口与日志等级同时保留。
2. 切换同字段冲突：定位 /server/port，展示双方候选与保留的 base。
3. 切换比较模式和大整数示例：9007199254740992 → 9007199254740993，输出精确补丁。
4. 切换补丁模式，演示失败的 test 返回具体路径。
5. 展示 CLI 冲突退出码及 MoonBit 测试结果。
